# 図版の作り方と規則

[連載目次へ](../README.md)

本文に差し込む図は、`scripts/draw_figures.py`（Python標準ライブラリのみ）が生成するSVGである。画像編集ソフトで描かず、生成コードを編集して再生成する。

## 変更の手順

```sh
python3 scripts/draw_figures.py
python3 scripts/validate.py
python3 -m unittest discover -s tests
python3 scripts/build.py
python3 scripts/check_html.py
```

SVGを直接直すと、次の再生成で上書きされる。テストが、リポジトリのSVGと生成コードの出力のずれを検出する。

## 一覧の管理

- 図は `assets/illustrations/NN-x-slug.svg`（回番号、枝番、短い名前）に置く。
- `series.json` の各回の `figures` に、本文での登場順にファイル名を並べる。検査は、本文の参照、キャプションの連番、`figures` の数と順序が一致することを確かめる。
- 本文では `![代替テキスト](../assets/illustrations/NN-x-slug.svg)` の直後に、空行を置いて `*図N-k：前提と帰結*` を書く。SVGのコードを本文へ貼らない。
- 代替テキスト（`alt`）は図の内容、SVGの副題（`desc`）は何を見るか、キャプションは前提と帰結を書き、役割を分ける。

## 置き方と密度

- 図は、その内容を説明し終えた段落の直後に置く。次の節の内容を先に見せない。総括の節には付けない。
- 1枚につき主張は一つ。パネルは2枚まで。ラベルは10個前後を目安にする。
- 密度は本文1,100〜2,000字に1枚を目安とし、その節で初めて出る概念か、具体例のある場面に付ける。

## 見た目の規則

- 幅1200pxを基準にし、背景は紙色（`#f7f5ef`、角丸）のカードとする。ダークモードでも図は変えない。
- 上部に連載コード・回・図番号、題名（34px）、副題（21px）、区切り線を置く。下端に、図の結論を一文で置く（19px）。
- 文字は14px以上。ラベルは16px、注記は14pxを基本にする。箱と箱の間の矢印は24px以上の長さを取る。矢じりは線と同じ色にする。
- 実線は流れ・因果、破線は仮説・確認・補助的な関係を表す。色は意味を凡例か見出しで書き、色だけで区別しない。
- 色の使い分け：青＝原典の記述・主たる流れ、青緑＝後続・実現済み、琥珀＝筆者の解釈・仮説・設計案、紫＝生成AI、灰＝未定義・補助。
- 生成コードは文字幅を見積もり、枠や画面からはみ出す文をエラーにする。

## イメージ図（比喩）

構造や手順ではなく、情景で概念を想起させる図をイメージ図と呼ぶ。

- 事実の根拠にしない。図の中に「イメージ」のバッジを描き、キャプションを「図N-k：（イメージ）…」で始める。テストが、バッジとキャプションの対応を確かめる。
- 実在の人物、史料、画面は描かない。器・水・糸・階段など、抽象的な形に限る。
- 原典の手順やアルゴリズムの図解に見えないようにする。特に第2回では、筆者の理解を示す比喩であることをキャプションに書く。
- 文字は少なく（ラベル6個前後）にとどめ、図の結論を下端の一文で示す。
- 表紙は回に属さない。`series.json` の `cover` に登録し、`README.md` の目次ページの先頭に、キャプションなしで置く。

## ひとこま（文字を入れない小さな線画）

本文の区切りに添える、モチーフ一つだけの小さな線画をひとこまと呼ぶ。図とは別の種類で、番号もキャプションも付けない。

- 置き場は `assets/vignettes/NN-x-slug.svg`。`series.json` の各回の `vignettes` に、登場順に登録する。
- 本文では、空の代替テキストで `![](../assets/vignettes/NN-x-slug.svg)` と書き、前後に空行を置く。代替テキストが空の画像は、ひとこまに限る。
- 文字を入れない。背景は透明で、線は中間色と、アクセント1色にとどめる（明るい背景でも暗い背景でも読める）。
- 事実を主張しない。実在の人物・史料・画面、結果や測定値に見える線を描かない。既存の図と同じ題材を使わない。
- 総括の節には付けない。目安は1回に1〜2点。
- サイトでは `aria-hidden` の装飾として出力し、幅は本文の約3分の1に収める。

## 実績の見せ方（AGENTS.md の規則）

- 設計案や未実施の実験を描く図には、図の中にも「設計案」「例示」「実験計画（未実施）」のバッジを付ける。キャプションと切り離されても誤読されないようにするためである。
- 例示の図に、AIが抽出した結果や測定値のように見える線・数値を描かない。
- 図に新しい人名・年代・書名・数値を入れるときは、本文と一致させ、`editorial/verification-log.md` に確認結果を記録する。確認できていない内容は「要確認」として残す。

## SVGの制約

`viewBox`、`role="img"`、`title`、`desc` を持たせる。`script`、`foreignObject`、外部画像、外部フォント、イベントハンドラ、外部URLへの参照は入れない。日本語の表示は閲覧環境のフォントを使い、フォントファイルは同梱しない。検査（`validate.py`）がこれらを確かめる。
